# チームメイトの集め方

公開サーバーのロビーで人を集めるのはあまりお勧めしません。なぜなら、かなりの確率ですぐに抜けるからです、場合によっては、重要なときとかに抜けられることもあります。

<img src="images/Lobby.png" alt="ロビーの画像" width="600" height="400"></img>

なので、適当にDiscordのサーバーを見つけて、そこで仲間とやる(特にボイスでする)のがおすすめです。

Discordのサーバーを見つけるには、ディス速やDISBOARDなどで探すといいです。

- [ディス速](https://dissoku.net/ja)
- [DISBOARD](https://disboard.org/ja/)
