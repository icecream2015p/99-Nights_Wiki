# シチュー自動製造機の作り方

この装置は、その名の通りゲーム内で作れる最高の食料である「シチュー」を自動で生成してくれる装置です。

ここでは、僕がお勧めしているシチュー製造機の作り方を解説します。

他の作り方に関しては、このページの最後にリンクがあるので、そこから他のバリエーションを見てください。

必要な建築:

- 農地または魔法の農地
  - 量:好きなだけ
  - クラフト材料:木材10個
- クロックポット
  - 量:1個
  - クラフト材料:木材15個,鉄材10個
- 木材保管庫
  - 量:4個(余裕があるなら6個)
  - クラフト材料:鉄材5個
- 丸太の壁(余裕があるなら)
  - 量:未定(検証中)
  - クラフト材料:木材12個
